# Todo List App

A simple and interactive Todo List web application built using HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Clean and responsive UI
- 
Live Demo-https://to-do-list-red-one-99.vercel.app/

## Tech Stack
- HTML
- CSS
- JavaScript
